# 暴雨永川 · 线上应急救援纪实

> H5 互动新闻作品 | 2025年永川特大暴雨

## 作品简介

本作品以2025年7月重庆永川特大暴雨为背景，通过6页极简H5 + 3个应急互动游戏，让用户在模拟救援中学习应急救援知识。

## 页面结构

| 页码 | 内容 | 交互方式 |
|:--:|------|------|
| P1 | 封面：暴雨城市背景 + 标题 | 自动雨滴动效 |
| P2 | 灾情简介 + 数据说明 | 按钮引导 |
| P3 | 互动一：寻找救援道具 | 点击探索 + 滑动清理障碍 |
| P4 | 互动二：核心救援游戏 | 长按/拼图/顺序点击/拖拽 |
| P5 | 互动三：授旗领奖 | 滑动揭幕 + 分享 |
| P6 | 科普总结 + 致敬 | 按钮重启 |

## 技术栈

- 纯原生 HTML5 + CSS3 + Vanilla JS
- 无框架、无插件、单文件部署
- 移动端触摸事件适配
- rem/vw 响应式布局

## 文件结构

```
yongchuan-h5/
├── index.html              # 主文件（单文件包含全部CSS/JS）
├── assets/
│   ├── images/             # 图片素材（AI生成 + 手动优化）
│   │   ├── bg_*.jpg        # 5张页面背景
│   │   ├── certificate_bg.jpg  # 证书模板
│   │   └── icon_*.png      # 10+个游戏道具图标
│   └── audio/              # 语音引导（TTS合成）
│       └── *.mp3           # 7段语音提示
└── README.md
```

## 部署方式

直接将整个 `yongchuan-h5/` 文件夹上传到任意静态托管服务：

- **GitHub Pages**（推荐）：推送后自动部署，HTTPS，长期有效
- **Vercel / Netlify**：拖拽文件夹即可
- **腾讯云COS / 阿里云OSS**：国内访问更快

## AI 使用标注

本作品在以下环节使用了AI辅助：

| 环节 | AI 工具/模型 | 用途说明 |
|------|------------|---------|
| 视觉素材 | 阿里云百炼 · 通义万相2.7 | 生成5张场景背景图 + 10+个游戏道具图标 |
| 语音引导 | 阿里云百炼 · Sambert语音合成 | 生成7段中文语音提示 |
| 部分文案 | 通义千问 Turbo | 辅助润色引导语和科普文案 |
| 代码辅助 | Claude Code | 辅助编写部分交互逻辑 |

> 所有AI生成素材均经过人工筛选、后期处理和压缩优化。
